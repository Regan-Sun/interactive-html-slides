# 交互式 HTML 幻灯片

**把你的主题、讲稿或题目，交给 AI 做成一份可以翻页、揭题、计时的网页演示稿。**

适合培训师、老师、活动主持人，以及组织即兴演讲的人。你不用自己写代码，只需要告诉 AI 这次讲什么、给谁看、想怎么互动。

## 这个 Skill 到底是什么？

你可以把 Skill 理解成一份“给 AI 的工作说明书”。

平时你让 AI 做演示稿，可能每次都要交代：题目先藏起来、点击后再显示、答案别提前露出来、演讲要计时……这个 Skill 把这类要求整理好了，让 AI 制作时有一套可遵循的做法。

**它本身不是一个打开就能播放的演示软件。** 你需要在支持 Skill 的 AI 工具中使用它，让 AI 根据你的内容生成演示文件。

## 用它能做什么？

| 你想做的事 | 它可以帮助 AI 制作的效果 |
| --- | --- |
| 组织即兴演讲 | 每次展示一道题，配上演讲计时 |
| 做课堂问答 | 先让大家看题、思考，再展示答案或知识点 |
| 开培训或工作坊 | 把方法、练习和总结分成一页一页展示 |
| 主持现场互动 | 用键盘翻页、揭题，按需进入全屏 |
| 调整已有互动演示页 | 修改题目、颜色、时间等，保留其他内容 |

这些功能按需要选。你可以明确说“不要计时器”或“不需要答案页”，也可以指定颜色、页数和演讲时长。

## 最后会得到什么？

通常是一份以 `.html` 结尾的文件，例如：

`有效沟通-互动演讲.html`

保存到电脑后，用浏览器打开就可以演示。默认做成一个独立文件，播放时不用安装 PowerPoint，也不依赖网络；制作时仍需要使用 AI 工具。

它看起来像能翻页的 PPT，但文件格式是网页。需要在 PowerPoint 中编辑的 `.pptx` 文件时，应另外提出该需求，这个 Skill 不负责生成 PPTX。

## 怎么开始用？

如果你的 Codex 已经装好了这个 Skill，直接发送下面这样的要求：

> 使用 $interactive-html-slides，帮我制作一份“有效沟通”主题的互动演讲网页。听众是公司同事，包含 8 道即兴演讲题。题目先隐藏，点击后展示，再点击显示一个沟通知识点。每人讲 1—2 分钟，需要计时和全屏。整体简洁，文字大一点。

还没安装时，可以把本仓库链接交给支持技能安装的 AI 工具，请它协助安装。手动安装则需要下载整个仓库，把文件放进该工具支持的技能目录，文件夹命名为 `interactive-html-slides`。保留内部目录结构，不要只复制一个文件，也不要多套一层文件夹。

仓库地址：https://github.com/Regan-Sun/interactive-html-slides

不同工具的安装目录可能不同，请以你使用的工具为准。

## 不知道怎么提要求？照着这几个例子说

### 做一场课堂问答

> 使用 $interactive-html-slides，把下面的 6 道题做成互动网页。先显示题目，再显示参考答案。不要计时器，使用白底黑字，适合教室投影。题目如下：……

### 把培训材料变成现场练习

> 使用 $interactive-html-slides，根据我提供的培训材料，做一份“如何给同事反馈”的互动演示稿。先讲方法，再安排 4 道情景练习，每道练习后展示讨论要点。总时长约 20 分钟。

### 修改已有文件

> 使用 $interactive-html-slides，修改我上传的 HTML：红灯提示改到 3 分钟，并把第 2 道题替换成下面这道题。其他内容和样式保持不变。新题目：……

你提供得越清楚，结果越容易符合预期。优先说清楚：**主题、听众、内容、需要的互动功能、风格或时长。** 有现成讲稿或题库，直接一起提供。

## 演示时怎么操作？

启用相应功能时，通常按以下方式操作；最终以生成文件的按钮和操作说明为准。

| 操作 | 通常的效果 |
| --- | --- |
| 左右方向键 | 上一页、下一页 |
| 空格或回车 | 逐步展示题目、知识点，完成后翻页 |
| 点击页面按钮 | 揭题或查看知识点 |
| 计时按钮 | 开始计时；停止时是否归零，看按钮说明 |
| 全屏按钮或 F 键 | 进入或退出全屏 |

如果使用默认的即兴演讲计时，1 分钟显示绿灯，1 分 30 秒显示黄灯，2 分钟显示红灯。需要别的时长，可以在制作时说明。

## 使用前知道这几件事

- **每份演示稿仍然需要检查。** 正式活动前，用实际播放的电脑打开，试一下翻页、揭题、计时和投影效果。
- **AI 生成的事实和引用需要核对。** 尤其是研究数字、名人名言和所谓“官方规定”。
- **生成文件不等于发布网站。** 想让别人点击网址访问，还需要另外托管或发布；本仓库是技能说明，不是在线演示页面。
- **这里提供的是制作规则。** 仓库中的评测场景是检查清单，不代表所有生成结果都已经测试通过。
