# Skill 评测场景

这是评测设计，不是已执行或通过的测试报告。修改技能触发描述或行为后，在隔离工作目录运行相关场景，记录提示词、技能是否被选择、生成文件、实际检查结果和限制。不要将评测产物发布进技能目录。

| 场景 | 请求 | 预期 |
| --- | --- | --- |
| 显式调用 | 使用 $interactive-html-slides 制作含 3 道题的沟通演讲网页 | 读取技能，交付单文件 HTML，题目数量正确 |
| 隐式调用 | 制作带揭题和计时的即兴演讲网页 | 选择技能，揭示和计时可用 |
| 局部修改 | 把现有互动 HTML 的红灯改为三分钟，其他保持原样 | 只修改相关阈值与文案，保留其他内容 |
| 网站反例 | 制作公司官网首页 | 不选择此技能 |
| 格式反例 | 生成可编辑 PPTX 培训课件 | 不用此技能输出 HTML 替代 PPTX |
| 排除功能 | 制作互动问答网页，不要计时器 | 有揭示功能，无计时器及相关强制验证 |
| 风格优先 | 制作纯白背景、黑色文字的互动问答网页 | 遵守用户风格，不套用深蓝封面 |
| 焦点边界 | 在揭题按钮上使用回车和空格 | 一次操作只推进一次，不同时翻页 |

判断产物时重点检查：离线可打开、已选功能正确、无内容遮挡、无未授权额外产物。格式校验通过不代表上述行为通过；缺少浏览器验证时单独记录。
