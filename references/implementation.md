## 已观察到的结构

这是网页式幻灯片，不是 PowerPoint 转换文件，也不需要在线网址才能运行。全部 CSS 与 JavaScript 内嵌在 HTML 中，没有外部脚本、样式、图片、网络请求或后端。

DOM 仅先放置 `#deck` 和底部 `.bar`；JavaScript 的 `addSlide()` 创建 section 并加入 `slides` 数组。构成是 1 页封面、1 页四卡片知识点、10 页问题、1 页结尾，共 13 页。

`topics` 数组每项包含 `tag`、`subtext`、`q`、`point`。`subtext` 为 true 时切换酒红色题号、标签和按钮。内容通过模板字符串和 `innerHTML` 渲染，源数据直接写在脚本中。

## 导航与揭示

`show(i)` 将索引限制在有效范围，切换 `.active`，更新页码。`.slide` 默认隐藏，`.slide.active` 使用 flex 展示。

| 状态 | CSS 类 | 可见内容 | 空格/回车效果 |
| --- | --- | --- | --- |
| 未揭题 | 无 open/done | qmask 遮罩 | 加 open |
| 已揭题 | open | qbody 问题与 qbtn | 加 done |
| 已展开 | open + done | 问题与 qpoint 知识点 | 下一页 |

`reveal()` 返回是否在本页推进了揭示状态；返回 false 时由键盘处理器调用 next()。左右键直接翻页。事件委托通过 closest() 判断遮罩和知识点按钮。切换页面不移除 open/done，因此返回时保留状态。

## 计时与全屏

`toggleTimer()` 使用 setInterval，每秒 sec++；再次触发时 clearInterval 并清零，并非暂停。阈值依次为 60 秒绿、90 秒黄、120 秒红；达到 120 秒后继续计时。翻页与计时相互独立。T 切换计时，F 通过 Fullscreen API 进入/退出全屏。

## 值得保留与需要改进

保留：单文件离线交付、数据与控制分离、渐进揭示、主持人键盘操作、统一设计变量、动态页码。

制作新文件时改善这些已从源码观察到的问题：

- 全屏调用未处理不可用或拒绝的情况。
- 计时依赖回调次数，后台节流可能导致偏差。
- 全局回车/空格处理没有区分按钮焦点、输入区域或长按事件。
- 揭题使用 div，缺少按钮的键盘语义。
- 全局 overflow:hidden 加上最小字体、固定控制栏，窄屏或低高度下存在裁切风险；源文件只处理了卡片列数。
- 内容直接插入 innerHTML，不宜扩展为未经转义的外部内容输入。
- “成年人只能记住 20%–50%”及手册归属在文件中没有可核查的出处，生成新主题时不能当作已验证事实。

这些是源码层面的观察和风险判断，不是已复现的浏览器故障。
