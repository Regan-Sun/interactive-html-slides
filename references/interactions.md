# 可选交互约定

仅采用用户需要的功能；下列为默认行为，用户明确要求优先。

## 逐步揭示与导航

题目页依次显示遮罩、题目、知识点；没有知识点的题目跳过该阶段。空格/回车推进当前阶段，已完成时翻页；普通页直接翻页。左右方向键及 PageUp/PageDown 直接翻页，首尾停留。返回页面保留揭示状态。

点击揭题和显示知识点使用语义化按钮。快捷键忽略输入框、可编辑区域、组合键和长按重复事件；焦点在按钮上时保留原生空格/回车行为，避免同时触发全局推进。提供可见焦点与按钮名称，尊重减少动画偏好。

验证点击与键盘路径、首尾边界、返回状态及按钮焦点下不重复推进。

## 演讲计时

仅在需要计时时提供。即兴演讲缺省为 60/90/120 秒绿/黄/红提示，指定时长优先；显示时间或阶段文字，不仅依靠颜色。使用单调时间差计算已过时间，interval 只刷新显示。

沿用案例时按钮语义为“开始 / 停止并归零”，不是暂停；翻页不自动重置。用户要求暂停/继续时实现并清楚标注该语义。

验证开始、停止/重置或暂停/继续，以及每个阈值前后边界。默认阈值可检查 59/60、89/90、119/120 秒；自定义阈值相应调整。有合适测试能力时使用受控时间源，不在交付页保留测试入口。

## 全屏

需要时提供按钮和 F 快捷键。检查 Fullscreen API 能力并处理失败，失败后普通演示仍能使用。实际验证进入与退出；环境禁止时说明限制，不宣称通过。
